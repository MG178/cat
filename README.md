> **CollegeHub** — учебный MVP автоматизированной системы управления учебным процессом колледжа. Проект включает:
> - **WPF-клиент** для демонстрации пользовательских сценариев;
> - **REST API** на базе FastAPI (Python);
> - **Базу данных MS SQL Server**, разворачиваемую в Docker.
>
> Основные функции: ролевой доступ (администратор / студент), управление расписанием, генерация QR-кодов для занятий и учёт посещаемости.

---

## Что умеет приложение

### Администратор
- Вход по учётной записи администратора.
- CRUD пользователей (студенты, преподаватели).
- Управление группами, предметами и расписанием.
- Генерация QR-кода для конкретного занятия (с настраиваемым временем жизни).
- Просмотр статистики посещаемости по группам и студентам.
- Деактивация активной QR-сессии.

### Студент
- Вход по учётной записи студента.
- Просмотр личного расписания.
- Сканирование QR-кода (ввод кода вручную в клиенте) для отметки посещаемости.
- Просмотр истории своих посещений с указанием статуса (present / late / absent).

## Запуск проекта

### 1. Подготовка базы данных (Docker)

```bash
docker-compose up -d db
```

Скрипт инициализации (`init.sql`) автоматически создаст базу `CollegeHub`, таблицы, ограничения и заполнит справочники.

### 2. Запуск серверного API

```bash
cd api
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

API будет доступно по адресу `http://localhost:8000`.  
Документация Swagger — `http://localhost:8000/docs`.

### 3. Запуск WPF-клиента

Откройте решение `catprogram.slnx` в Visual Studio 2022 и запустите проект `catprogram`.  
Убедитесь, что в `appsettings.json` указан корректный адрес API:

```json
{
  "ApiBaseUrl": "http://localhost:8000"
}
```

## Основные возможности интерфейса

- **Окно входа** — авторизация по email и паролю.
- **Главное окно** — динамический набор вкладок в зависимости от роли:
  - **Расписание** (студент) — таблица занятий на текущую неделю.
  - **Посещаемость** (студент) — история отметок.
  - **Сканирование QR** — поле для ввода кода и кнопка отметки.
  - **Управление** (администратор) — вкладки: Пользователи, Группы, Предметы, Расписание, QR-генерация, Статистика.
- **QR-генерация** — выбор занятия, настройка времени действия, отображение сгенерированного QR-кода (текстовое представление).
- **Статистика** — сводные таблицы по группам с фильтрацией.

---

## Примечание

- **QR-коды** в текущей версии представлены текстовыми идентификаторами (UUID), которые можно скопировать и вставить в поле сканирования. Реализация графического QR-кода остаётся опциональной.
- Все бизнес-правила (проверка времени посещения, расчёт статуса «опоздал», уникальность отметки) выполняются на стороне сервера.
- Клиент не содержит логики, кроме отображения данных и отправки HTTP-запросов — это **чистый демонстратор API**.
